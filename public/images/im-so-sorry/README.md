# I'm so sorry photo trend sample slides

The `/im-so-sorry` carousel ships five sample frames in this folder. They are results made with this product (a Halloween costume set), not empty placeholders.

Each file is a 1080×1440 JPEG. **Admin → Effects → im-so-sorry** can replace any slot with an `https://` or same-site URL. Leave the field empty to keep the shipped file.

| File | What it shows |
| --- | --- |
| `01-dream.jpg` | First frame. Dream version of one photo. |
| `02-wig.jpg` | Wig confession frame. |
| `03-costume.jpg` | Costume confession frame. |
| `04-party.jpg` | Party confession frame. |
| `05-original.jpg` | The original photo with **no** caption drawn in the file. The page paints `i'm so sorry` (Spanish: `perdón`) in the burned-caption style. |

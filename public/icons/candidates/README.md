# AIGifMeme icon candidates

Nine favicon and app-icon options. The live files in `public/` (`favicon.ico`, `logo.png`, `apple-touch-icon.png`, and the other shipped sizes) stay as they are until one of these is chosen.

Each option has a 512×512 PNG (the picture to judge) and an SVG sketch. Open the PNGs. Reply with the filename, for example `04-monogram-ag-lime`.

| File | Mark | Colors |
| --- | --- | --- |
| `01-letter-a-punch` | Letter A | Punch `#FF2F86` on cream `#FFF6EE` |
| `02-letter-a-ink` | Letter A | Ink `#1A1024` on lime `#D6FF3C` |
| `03-letter-a-blue` | Letter A | Blue `#2F5BFF` on paper `#FFFDF8` |
| `04-monogram-ag-lime` | AG | Lime field, ink letters |
| `05-monogram-ag-cream` | AG | Cream field, punch letters |
| `06-sticker-burst` | Star burst | Yellow `#FFE14A`, ink stroke |
| `07-speech-gif` | GIF | Paper field, blue letters |
| `08-loop-mark` | Loop arrow | Ink field, punch arrow |
| `09-smiley-halftone` | Smiley | Punch field, yellow face |

After a pick, copy that artwork into `public/logo.png`, `public/favicon.ico`, `public/favicon-32.png`, `public/apple-touch-icon.png`, `public/icon-192.png`, `public/icon-512.png`, and `public/og.png`. Do not delete this folder until then.

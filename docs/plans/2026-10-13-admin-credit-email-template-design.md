# 后台赠送 Credits 邮件模板设计

## 目标

在管理后台的手动群发窗口内加入可复用的赠送 Credits 邮件模板。管理员可以选择常用赠送数量或填写自定义正整数，套用后继续编辑、预览、发送测试邮件，并沿用已有群发流程。

## 交互

- 在邮件编辑窗口加入模板选择、数量选择和“套用模板”操作。
- 数量默认 5；提供 5、10、20、50 等常用档位和自定义数量输入。
- 套用模板会切换为 HTML 格式，并替换当前主题和正文。按钮旁明确提示这一点；未点击套用前，选择数量不会覆盖正在编辑的内容。
- 套用后主题和 HTML 仍可手动编辑；现有预览、测试发送、确认收件人和批量发送交互保持不变。

## 邮件内容

- 延续此前确认的英文赠送通知文案，标题和正文中所有数量都由同一个 Credits 参数生成。
- 使用品牌色 `#D51F50`、站点 logo 的 Base64 PNG、隐藏摘要、数量徽章和站点 CTA。
- 从 `envConfigs.app_name` 和 `envConfigs.app_url` 获取品牌名和链接，避免在后台组件中写死应用配置。
- 仅插入经校验的正整数和经 HTML 转义的配置字符串；不接受用户输入作为任意 HTML 模板变量。

## 实现范围

- 新增纯函数模板生成器，返回邮件主题和 HTML 正文。
- 在 `ManualEmailDialog` 中增加模板控件和套用逻辑。
- 为新增可见文案补充英文、中文、西班牙文和阿拉伯文翻译。
- 不新增模板管理页面、保存草稿、数据库表、API 或邮件发送供应商配置。

## 验证

- 运行 `pnpm build`，由项目脚本同时执行 i18n 编译和检查。
- 确认生成的 HTML 在数量、主题、图标 data URI、站点链接和 HTML 转义上正确。
- 每次提交前运行仓库 `security-scan` 并人工复核变更。

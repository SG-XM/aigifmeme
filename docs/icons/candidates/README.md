# FileMeta Wipe icon candidates

Nine earlier favicon / app-icon sketches. The live mark is the white capital F on a translucent document, on a teal-to-cyan rounded square (`public/logo.png` and the favicon set). **04** was the previous default.

| File                     | Mark                    | Colors                                   |
| ------------------------ | ----------------------- | ---------------------------------------- |
| `01-letter-f-teal`       | Letter F                | Teal `#0E6B64`, paper `#F7F4EE`          |
| `02-letter-f-navy`       | Letter F                | Navy `#10243E`, copper `#D4783A`         |
| `03-letter-f-signal`     | Letter F                | Ink `#1C1917`, signal red `#E24B4B`      |
| `04-document-wipe-teal`  | Page with a wipe stroke | Teal and paper. Previous default        |
| `05-document-wipe-navy`  | Page with a wipe stroke | Navy and copper                          |
| `06-document-wipe-paper` | Page with a wipe stroke | Paper field, teal stroke                 |
| `07-eraser-bar-teal`     | Page with an eraser bar | Teal and paper                           |
| `08-eraser-bar-signal`   | Page with an eraser bar | Ink and signal red                       |
| `09-eraser-bar-paper`    | Page with an eraser bar | Paper field, teal bar                    |

Each option has an `.svg` and a 512×512 `.png`. The default set in `public/` is `logo.svg`, `logo.png`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, and `og.png`. Theme color is `#0E6B64`.
